# 标题长度校验——等价类/边界值设计表（第16次课）

## 缺陷描述

CampusFix 创建工单时标题没有长度限制，超过 20 字符的标题会破坏列表与详情页布局。

## 设计表

| 输入条件 | 有效等价类 | 无效等价类 | 边界值（用例） |
|---|---|---|---|
| 标题长度 L | 1 ≤ L ≤ 20（正常标题） | L > 20（超长标题） | 19、20、21 |
| 位置 room | 非空字符串 | 空字符串 | — |

## 边界值用例设计

| 用例 | 输入（标题长度） | 预期结果 |
|---|---|---|
| 1 | L = 19（"A"×19） | 通过校验，返回 None（工单可创建） |
| 2 | L = 20（"A"×20） | 通过校验，返回 None（工单可创建） |
| 3 | L = 21（"A"×21） | 拒绝：返回错误提示 "标题不能超过20个字符"，路由返回 400 |
